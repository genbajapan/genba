# Genba

**Winning Japan Sales for SaaS & IT**

海外の中小SaaS企業・外資系IT企業向けに、日本エンタープライズ営業の現場経験に基づくアドバイザリーを提供する事業。

このリポジトリは、事業構想・ブランド定義・コンテンツ制作・競合調査などGenba立ち上げに関する情報を一元管理する場所。

## ディレクトリ構成

```
docs/            事業の中核ドキュメント(ブランド、事業概要、サービス設計など)
content/         発信コンテンツ(ブログ・X投稿)の下書き・公開済み・カレンダー・テンプレート
research/        競合・市場データなどの一次情報ストック
ops/             ガードレール、法務・利益相反チェックなど運用上の管理事項
```

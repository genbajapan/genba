# 発信カレンダー

5カテゴリ([docs/06-content-strategy.md](../../docs/06-content-strategy.md)参照)をローテーションしながら日次で発信する運用を想定したカレンダー。

## カテゴリ凡例

| # | カテゴリ |
|---|---|
| 1 | 商習慣・意思決定プロセス |
| 2 | 業界別の勘所(リテール/EC、OTA/旅行) |
| 3 | 市場データ・トレンド |
| 4 | セールス実践・戦略 |
| 5 | ケーススタディ・失敗談 |

## スケジュール

| 日付 | カテゴリ | 形式(Blog / X単発 / Xスレッド) | タイトル・トピック | ステータス |
|---|---|---|---|---|
| | | | | 未着手 |

> 行を追加して運用する。ステータスは `未着手 / 執筆中 / レビュー中(ガードレール確認済み) / 公開済み` を使用。

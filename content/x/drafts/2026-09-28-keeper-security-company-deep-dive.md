# X下書き: Keeper Security 1社深掘り

米国発。Keeper Securityを取り上げる理由は、パスワード保管から、管理者、機械、AIエージェントの「強い権限」を必要な時だけ渡す基盤へ広がっている会社だからです。

始まりは2011年。長く事業を共にしたDarren GuccioneとCraig Lureyが、本人以外は復号できないゼロ知識設計で認証情報を守る製品を立ち上げました。現在はパスワード、シークレット、特権アクセス、リモート接続、操作記録を一つの統制へつなぎます。

会社公式で150カ国超、導入企業93,000社超、保護利用者400万人。LinkedInの公開規模は501〜1,000人で、Vectra AIやCatapult Sportsと同じ帯です。時点と定義が異なる概数比較です。

「Microsoftや既存のパスワード管理で十分では？」という反論はもっともです。Keeperの勝ち筋は、人のログインだけでなく、サービスアカウント、開発用シークレット、管理者権限、AIエージェントの操作まで、最小権限と監査証跡でつなぐこと。AIが業務システムを操作するほど、誰に何をいつ許し、何を止めたかは基盤モデルだけでは管理しにくい。一方、既存ID基盤へ統一できる企業では追加投資になる可能性もあります。

丸三食品の公式事例では、部署・担当者単位で認証情報を共有し、細かな権限制御によって管理リスクの負担を軽減。数値成果は公開されておらず、他社への再現保証もありません。

今日時点での日本向け公式求人は1件。東京のCustomer Success Manager, APACは、導入と利用だけでなく、四半期レビュー、更新、追加販売、問題解決まで持つ売上責任を伴う顧客成功職です。

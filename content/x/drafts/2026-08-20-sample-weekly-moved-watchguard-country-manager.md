# X下書き見本: 今週動いた外資 WatchGuard

創業30年、世界150万超の顧客を守るセキュリティ企業で、今週いちばん気になった変化は「Tokyoの求人が1件出たこと」でした。

件数はたった1件。でも役職は、WatchGuardのCountry Manager - Japan。

WatchGuardは新しく日本へ来る会社ではなく、すでに日本法人と東京officeを持つ米国企業。ネットワーク、endpoint、identityなどのセキュリティを、主にMSPや販売partner経由で届けています。

今回の求人を見ると、任されるのは、

・日本のsales strategyとrevenue target
・sales teamの採用、育成、quota、KPI
・pipelineとforecast
・lead獲得からcloseまでのsales process
・distributor、channel、MSP partnerとの関係

などなど。

つまり「大口案件を取る営業責任者」というより、日本事業の営業OSを丸ごと持つ役割に近い。

ここが面白くて、WatchGuardは25,000超のMSPを通じて150万超の顧客を守るpartner-firstの会社。直販だけを増やすより、distributorとMSPが売りやすく、運用しやすく、儲けやすい仕組みを作ることが成長に直結します。

転職目線で勉強になるのは、求人シグナルは「何件増えたか」より「どこまでを1人へ任せようとしているか」で見ること。

AEが5件出るより、strategy、team、forecast、partnerまで持つCountry Managerが1件出る方が、組織の変化として大きい場合があります。

一方、これが欠員補充か増員か、日本事業がどの程度拡大するかは公開情報だけでは未確認。次はAE、Channel、SE、Marketingなど周辺職種が増えるかを見たいところです。

# Genba X(@chosenshi08)投稿戦略

最終更新: 2026-08-19

`ops/daily-workflow.md`のステップ4(コンテンツ候補を作る)から参照される、X投稿下書きの詳細方針。ここに書く内容は`ops/guardrails.md`・`ops/job-publication-and-sponsor-policy.md`の上位ルールに従う前提とする。

## 1. 目標

- 1年でフォロワー1万人
- 平均1〜2投稿/日
- アカウントは@chosenshi08(Genba公式)。創業者の実名・顔出しはしない現行方針を維持する([ops/guardrails.md](guardrails.md)「創業者の実名を出さない現在の方針」)
- @chosenshi08はX Premiumのため文字数制限(280字)はない。ただし長さを理由に冗長にしない。1投稿1メッセージの原則は維持し、長くする場合は具体例や根拠を足すためだけに使う

## 2. 基本シリーズ

日常運用では、次の3シリーズを軸にローテーションする。各投稿は1社または1つの教訓へ絞り、シリーズの必須要素をすべて同じ文字量で並べるのではなく、読者の判断に効く順に強弱をつける。

1. **中小規模外資IT紹介シリーズ**
   - どんな会社か、固有の魅力と成長性、考えられるリスク、公開済みの導入事例、AE観点で仕事が面白そうかを扱う
   - 製品は簡潔なFABE（Feature / Advantage / Benefit / Evidence）で、Buyerの課題から提案のイメージが湧くように説明する
   - リスクは根拠のない悲観論ではなく、求人、組織フェーズ、競争環境、公開情報の不足から応募前に確認すべき点へ落とす
2. **日本未進出注目外資シリーズ**
   - どんな会社か、固有の魅力と成長性、日本へまだ進出していない理由、簡潔なFABEを扱う
   - 未進出の理由は、確認できた事実と`Genba仮説`を明確に分ける。進出時期や確率を断定せず、日本で成立するために必要な条件を示す
   - 日本から現在応募できると誤認させず、求人・法人・拠点・国内顧客事例の確認状況を明記する
3. **転職Tips・営業活動シリーズ**
   - 外資IT転職、会社選び、面接質問、Territory、Quota、営業活動、課題啓蒙などから、共感・保存・引用されやすい1テーマを扱う
   - 意外性のある結論、具体的な質問・チェックリスト、短い教訓のいずれかを入れる
   - 創業者の一次経験は一般化し、現職・前職や非公開情報を特定できる書き方、作った統計や体験談を使わない

### 2-1. 定期シリーズ

通常の3シリーズに加え、読者が毎週追う理由を作る定期フォーマットとして、次の3シリーズを固定運用する。いずれも本文だけで判断価値を完結させ、Genbaへの誘導だけを目的にしない。

#### Genba二択

- 毎週水曜日21:30と日曜日20:30（Asia/Tokyo）に投稿する。日曜日分と次の水曜日分は、直前の土曜日の対話型`デイリータスク`でまとめて作成し、Jioが文章・口調・比較内容を確認した後に指定時刻へ予約する
- 毎回、Genbaに掲載中の具体的な企業2社を選び、1つの明確なテーマに対して同じ項目で比較する。抽象的な二択、1社だけの深掘り、企業名だけを差し替えた会社紹介にはしない
- 水曜日は`転職先としてどちらを選ぶか`を主眼に、Buyer、sales motion、製品の広がり、日本組織のphaseなど、仕事選びに直結する軸を扱う。現在応募できる前提のテーマでは、両社とも予約直前に日本向け公式求人の公開を確認できることを必須とする
- 日曜日は`どちらの市場・営業環境で戦いたいか`を主眼に、市場の成熟度、新市場形成か既存市場拡大か、直販かpartnerか、一点突破かplatformかなど、営業careerの考え方を学べる軸を扱う
- 日本未進出企業を含む場合は、現在応募可能な企業との転職先比較に見せない。日本法人、日本拠点、日本向け求人、国内顧客事例の確認状況と`Genba仮説`を分け、将来の市場観測として比較する
- 同一企業は、水曜日・日曜日を合わせた`Genba二択`全体で、前回の投稿日から最低28日間再登場させない。下書きと投稿履歴の両方を確認し、企業の偏りとマンネリを防ぐ
- 比較項目は原則2〜3点に絞り、両社で同じ定義・対象地域・確認時点を使う。片方だけ情報がない場合は推測で埋めず`未確認`または`非公開`と表示する
- 企業の優劣、応募推奨、勝者、ランキングを決めない。公式情報から確認できる事実と`Genba分析`を分け、読者が自分の志向で選べる材料を示す
- 冒頭で比較テーマと2社名を示し、末尾は`あなたならA/B、理由を一言で教えてください`を基本CTAとする。選択だけでなく理由を求め、届いた返信へ反応する場合は、その回の明示承認を得る
- Genbaへのリンクを置く場合は、両社の詳細を調べられることを明示し、実際の投稿日を使ったUTMを付ける。コメントCTAを弱めるほどリンクや告知を詰め込まない
- 画像を使う場合はGenba独自の比較cardとし、企業名、比較テーマ、同じ比較項目をスマートフォンで読める量に絞る。許諾のない企業logo、採用画像、社員写真を使わない
- スポンサー契約中の企業は、契約とJioの明示依頼なしに通常回へ組み込まない。扱う場合は`広告`または`PR`と`Sponsored`を明示し、対価によって比較軸、事実、分析、結論を有利に変えない
- 開始後4週間・計8投稿を一区切りとして、表示、1,000表示当たりの返信、profile access、Genba遷移、follow、repost・保存を曜日別に比較する。結果をJioへ報告し、頻度や時刻は自動変更しない

#### 今週動いた小中規模外資

- 毎週土曜日08:00（Asia/Tokyo）に投稿する。金曜日の対話型`デイリータスク`で、翌朝の指定時刻へ予約する
- 対象期間は、前回の同シリーズで確認対象を締めた後から、当該金曜日の`デイリータスク`実行時点までとする
- 対象はGenbaの中核である、日本進出済みだが日本語情報が乏しい小中規模外資とする。Adyen・決済領域、国内組織規模の基準を超えるアンカー企業、日本未進出企業を混ぜない
- 公式Career・公式ATS・公式ニュースルームで確認した、新規求人、募集終了、職種・segment・勤務地の変更、日本採用や日本組織の明確な変化から、読者の応募・継続観測判断に効くものだけを扱う。件数を揃えるために弱い変化や推測を加えない
- 冒頭で今週の最重要変化を一文で示し、各社は`企業名 / 確認できた変化 / 仕事として見る論点`を短くまとめる。終了求人は会社撤退や採用縮小と断定せず、事実から言える範囲と次に見るシグナルを分ける
- 末尾CTAは、当該企業ページまたは求人あり企業一覧で何を確認できるかを具体的に示す。Genbaへのリンクには実際の投稿日を使ったUTMを付ける
- 末尾に`#外資IT #転職`をこの順序で付け、他のハッシュタグは追加しない

#### 日本未進出外資ITレーダー

- 毎週土曜日22:00（Asia/Tokyo）に投稿する。土曜日の対話型`デイリータスク`で、同日夜の指定時刻へ予約する
- 1投稿につき日本未進出企業1社へ絞り、`ops/pre-entry-company-standard.md`に従って調査済みで、Genbaに日本未進出として掲載している企業から選ぶ
- 直近30日以内に同シリーズで扱った企業は原則再掲載しない。日本法人設立、Japan専任求人、国内顧客事例、正式な日本語対応などの重要な公式変化がある場合だけ例外とし、変化点を明示する
- 冒頭は固有の魅力または意外性のある事実から始める。`会社・製品の固有価値 / 日本未進出と確認できる事実 / 進出を支持する材料 / 反証・障壁 / 次に見るシグナル`の順で構成する
- 日本法人、日本拠点、日本向け求人、国内顧客事例の確認状況を明記し、日本から現在応募できる会社と誤認させない。進出時期、進出確率、最初の採用職種、報酬・Quotaを断定しない
- `Genba仮説`は、結論、支持材料、反証・留保、継続観測項目を分ける。資金調達やAPAC求人だけで日本進出を結論づけない
- 末尾CTAは、当該企業ページで確認できる支持材料・障壁・継続観測点を具体的に示す。Genbaへのリンクには実際の投稿日を使ったUTMを付ける
- 末尾に`#外資IT #転職`をこの順序で付け、他のハッシュタグは追加しない

## 4. 「バズる」ための優先基準

X上の外資IT界隈のリアルタイムトレンドには直接アクセスできないため、日々の「トレンド乗り」は狙わない。代わりに、共感・保存・引用されやすい普遍的な切り口を優先し、トピックリストの中から反応が取れそうな角度を選ぶ。

優先する型(いずれか、または組み合わせ):

- **あるある**: 外資IT営業なら誰もが「わかる」と思う具体的な瞬間
- **逆説・意外性**: 一般的な思い込みを覆す一言(例: 「大手より小規模の方が◯◯」)
- **具体的な数字**: 曖昧な形容詞ではなく、数字で言い切る
- **断定**: ヘッジせず言い切る。ただし事実確認できない統計は作らない([ops/guardrails.md](guardrails.md)3「AIが作った統計、事例、発言、引用を含まない」)
- **短い教訓**: 学びを1文に凝縮する

1投稿1メッセージとし、詰め込みすぎない。説明的・解説調になりすぎないよう、話し言葉に近いテンポを優先する。

## 5. 守ること(既存ガードレールの再掲ではなく適用の要点)

- 現職の社名・案件・顧客・価格・戦略には触れない([ops/guardrails.md](guardrails.md)1)
- 前職・現職を代表する見解に見えないよう、一般化した個人の経験として書く
- 断定的な投資助言に見える書き方を避ける(「お金・投資事情」トピック特有の注意点)
- 事実確認できない統計・事例・引用を作らない
- 下書きは`content/x/drafts/`へ保存し、明示依頼がなければ投稿しない(`ops/daily-workflow.md`の既存ルールを維持)

## 6. 運用

`/genba-daily`実行時に、この戦略に沿ってX下書きを2本作成する。投稿数を急に増やすのではなく、1日2本を基本に表示、保存、サイト遷移、ニュースレター登録を継続的に伸ばす。トピックは前回までの投稿と重複しないよう、直近の下書き・投稿履歴を確認してからローテーションする。土曜日の対話型`デイリータスク`だけは、`日本未進出外資ITレーダー`に加えて日曜日分・次の水曜日分の`Genba二択`2本を作るため、定期X下書きを合計3本作成してよい。`Genba二択`はJio確認後に`ops/daily-task-workflow.md`3-1に従って予約する。

火曜日・金曜日は、通常のX下書き2本を`ops/daily-task-workflow.md`3-2の本人向けX案メールへ置き換える。火曜日は公開X投稿の引用候補、金曜日はEnterprise AEとしてのoriginal投稿候補を3〜5件提示する。これはJioが選び、口調や実体験を加えるための編集材料であり、自動投稿・自動予約の対象にしない。金曜日の`今週動いた小中規模外資`は別枠で作成・予約する。

2本は原則として次の組み合わせにする。

1. **企業シリーズを1本**: `中小規模外資IT紹介`または`日本未進出注目外資`から1社を選び、該当するGenba企業ページへ計測リンクでつなぐ
2. **もう1本をローテーション**: `転職Tips・営業活動`を基本とし、強い採用・事業シグナルがある日はもう一方の企業シリーズへ差し替えてよい

直近7日間で3シリーズを最低1回ずつ扱う。同じ会社、同じ職種、同じ主張を続けず、投稿履歴と下書きを見て組み合わせを変える。転職Tips・営業活動は原則リンクなしとし、企業シリーズは有益な本文を完結させたうえで企業ページへつなぐ。

初期反応では、一般的なサイト告知よりも「特定企業＋応募・面接に使える情報」の方が保存と遷移につながったため、企業研究投稿を日次の主軸とする。`掲載社数`、`AIで作った`、`更新した`等の運営者目線だけで投稿を完結させない。Genba単独告知は全体の1〜2割以内とし、毎投稿へリンクを付けない。

### 6-1. 通常の企業研究とスポンサーX記事

- 通常の企業研究は短いX投稿とGenba企業ページを主軸とし、日次運用でXの記事化機能へ転載・量産しない
- Xの記事化機能は、スポンサー契約に基づく`広告｜Sponsored Company Brief`を主用途とする。通常の中立的な企業研究と誤認させる名称・表示を使わない
- スポンサーX記事は冒頭で`広告`と`Sponsored`を明示し、Xの有料パートナーシップ表示を有効にする。企業提供情報は`企業提供事実`、公開情報に基づく編集判断は`Genba分析`として分離する
- スポンサーは会社名、製品名、数字、求人状況等の事実確認を行えるが、通常順位、推薦、Genba分析、反証、注意点、面接質問の変更権は持たない
- 記事は日本事業、採用背景、営業組織、仕事としての魅力、未確認事項、公式求人へのCTAを基本構成とする。応募は公式採用ページへ送り、候補者情報をGenbaで受け取らない
- 記事から派生する告知投稿にも`広告`または`PR`と有料パートナーシップ表示を付ける。表示回数、記事閲覧、Genba遷移、公式求人クリックは集計値だけをスポンサーへ報告する
- 広告過多を避けるため、スポンサーX記事は原則月1社までとし、契約や明示依頼がない通常の`/genba-daily`では作成しない

### 6-2. Genbaへのリンク計測

X投稿から`genbajapan.com`へ遷移させるリンクには、公開前に以下のUTMパラメータを必ず付ける。外部の公式サイトや採用ページへ直接リンクする場合は付けない。

- `utm_source=x`
- `utm_medium=organic_social`
- `utm_campaign=YYYYMMDD_<topic>`（投稿日と投稿テーマ。半角英小文字・数字・アンダースコアのみ）
- `utm_content=post_<NN>`（同じキャンペーン内の投稿・クリエイティブ識別子）

例:

`https://genbajapan.com/companies/elastic?utm_source=x&utm_medium=organic_social&utm_campaign=20260815_elastic&utm_content=post_01`

- 投稿本文にGenbaへのリンクを置く場合、下書きの時点でプレースホルダーではなく最終URLを記載する
- 既存のクエリパラメータがあるURLでは、`?`を重ねず`&`でUTMを追加する
- 同じ投稿内の同じ遷移先には同じUTMを使い、A/B案や返信欄の別導線は`utm_content`を変えて識別する
- UTM値へ氏名、メールアドレス、企業の非公開情報などを入れない
- 公開前にリンク先が200で表示されることと、4つのUTMが保持されることを確認する

# Genba発信・公開ガードレール

最終更新: 2026-08-05

ブログ、企業・求人データ、採用シグナル、ニュースレター、X投稿、スポンサー制作物の公開前に確認する。

## 1. 機密・利益相反

- [ ] 現勤務先の社名、案件、顧客、価格、戦略、社内情報に言及していない
- [ ] 過去の勤務先についても、公開情報または一般化できる本人の経験だけを使っている
- [ ] 勤務先を代表する見解に見えない
- [ ] 顧客・同僚・候補者を特定できる情報を含まない
- [ ] 非公開資料、社内会話、商談情報を根拠にしていない

## 2. 企業・求人・採用シグナル

- [ ] 企業公式Career、公式ATS、公式ニュースルームなどの出典がある
- [ ] 出典URLを実際に開いて内容を確認した
- [ ] 初回確認日・最終確認日が正しい
- [ ] 求人票を大量転載せず、事実を独自に要約している
- [ ] 給与、OTE、言語、勤務形態、担当社数を推測で埋めていない
- [ ] 応募・合否データと公開済み算出方法がない状態で、合格確率を表示していない
- [ ] 社員数、AE人数、在籍年数、人材流動は対象地域・職種・期間・サンプル数・出典を明示している
- [ ] 公開プロフィール由来の情報は集計値として扱い、社員個人の一覧、人物評、未確認の経歴を掲載していない
- [ ] 事実と`Genba分析`が表示上分かれている
- [ ] `Genba仮説`には結論、確度、支持材料、反証・留保、面接での検証質問がある
- [ ] 仮説の根拠に対象地域・職種・期間の異なる情報を使う場合、その限界を明記している
- [ ] コミュニティ情報や自己申告集計だけで、会社・日本法人・特定チームを断定していない
- [ ] 公式情報と外部情報が食い違う場合、片方を隠さず差異を示している
- [ ] 募集終了・リンク切れ・重複を確認した
- [ ] 許諾のないロゴ、画像、社員写真を使用していない

詳細は[求人掲載・スポンサー運用ポリシー](job-publication-and-sponsor-policy.md)を参照する。

## 3. 編集コンテンツ

- [ ] 新しい日本語メディアの読者である、外資SaaS営業・転職潜在層に役立つ
- [ ] 旧アドバイザリー事業の営業記事を惰性で増やしていない
- [ ] 数字、日付、企業名、役職名、引用、リンクを再確認した
- [ ] AIが作った統計、事例、発言、引用を含まない
- [ ] 二次情報だけで断定せず、可能な限り一次情報を示している
- [ ] 転職を不必要に煽らず、判断材料を提供している
- [ ] 創業者の実名を出さない現在の方針と整合している

## 4. スポンサー・広告

- [ ] `広告`、`PR`、`スポンサー`のいずれかを読者が認識できる位置に表示した
- [ ] 対価によって通常順位、企業評価、分析結論を変えていない
- [ ] スポンサーの主張を編集部の事実認定として書いていない
- [ ] 企業提供の一次情報を`企業提供事実`としてGenba仮説と分離している
- [ ] 読者個人データをスポンサーへ提供していない
- [ ] 料金、発生条件、契約期間、解約方法を企業へ事前提示した
- [ ] スポンサーの採否について、勤務先との利益相反を確認した

## 5. 職業紹介との境界

- [ ] Genba内で応募を受け付けていない
- [ ] 候補者情報・応募書類を企業へ渡していない
- [ ] 候補者ごとの求人選別・個別マッチングをしていない
- [ ] 面接調整、連絡仲介、条件交渉をしていない
- [ ] 採用成功報酬を受け取る設計になっていない

該当する可能性がある場合は公開・契約を止め、[法務チェックリスト](legal-checklist.md)に従って確認する。

## 6. 外部操作

- [ ] 対話セッションのpush・デプロイは`PROJECT_RULES.md`7章の自動公開条件を満たしている
- [ ] X投稿、メール配信、スポンサー連絡について今回の明示承認がある
- [ ] スケジュール実行の場合、`ops/daily-workflow.md`7-1の公開可能範囲を超えていない
- [ ] 承認・自動公開の範囲を超えた外部操作を含んでいない
- [ ] `npm run check`が成功した
- [ ] `git diff --check`が成功した
- [ ] 他方のエージェントやJioの変更を上書きしていない

X投稿、メール配信、スポンサー連絡の承認がない場合は、それらだけを下書き・公開候補までで停止する。

# 発信ガードレール

**すべてのブログ記事・X投稿の公開前に、このチェックリストを確認すること。**

## 禁止事項

- [ ] Adyenの社名に言及していないか
- [ ] Adyenの内部の案件・顧客情報に言及していないか
- [ ] Adyenの価格戦略に言及していないか

## 書き方のルール

- [ ] 発信内容は「個人の一般化できる経験・見解」として書かれているか
- [ ] Adyenを代表する見解であるかのような書き方になっていないか
- [ ] 実績訴求はCisco/Shopify時代の経験を中心に据えているか(Adyen在籍をプロフィールに記載すること自体は問題ない)

## 案件化に関するルール

- [ ] Adyen在職中に有料クライアントの契約・営業を行っていないか(発信のみに留める)
- 利益相反リスクの法務確認状況は [legal-checklist.md](legal-checklist.md) を参照

## 背景

Genbaのブログ・Xアカウントは創業者Jio個人の発信であり、Adyenとの利益相反(業務上知り得た情報の流用、競業避止条項違反、勧誘禁止期間中の営業活動など)を避けることが事業継続の前提条件。詳細は [docs/08-open-items.md](../docs/08-open-items.md) を参照。

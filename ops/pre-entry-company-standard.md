# 日本未進出企業ページ標準

最終更新: 2026-08-12

このファイルは、日本法人・国内拠点・日本向け求人を確認できない注目企業の個別ページに関する正本である。Gongページを起点にJioと改善して確定した構造と情報密度を、会社名に依存しない共通仕様として固定する。

Gong固有の文章・数値・結論を他社へコピーしない。固定するのはフォーマット、調査範囲、事実と仮説の分離、読者へ与える判断材料の深さである。

## 1. 適用条件

- 日本法人、日本オフィス、日本向け公式求人のいずれも確認できない企業は、`entryStatus: "not-entered"`とする
- 日本法人・常設拠点は確認できないが、日本法人・拠点設立予定の公式発表、日本責任者・日本市場担当者の配置、現行の日本市場向け公式求人など、具体的な動きを確認した企業は`entryStatus: "pre-entry-signal"`とする。現行シグナルがある場合の表示は`日本進出の兆しあり`、過去求人のみを履歴として保持する場合は`過去に日本進出の兆しあり`とし、後者を現行シグナルの絞り込みへ含めない
- `日本進出の兆しあり`は「日本に社員がいない」という意味ではない。日本在住・日本担当者がいる場合も含み、公開情報で日本法人の登記または公式な常設拠点を確認できない一方、現在の具体的な動きを確認した状態を示す。本国法人との直接雇用、EOR等の可能性はあるが、雇用主体は公開根拠がない限り断定しない
- 法人・常設拠点、日本在住・日本担当者、現行求人の3軸を分ける。Remote Japan求人やJapan territory求人だけで、法人設立・国内拠点・国内顧客を断定しない
- 国内情報が少ないことを理由に、通常企業ページより薄くしない
- `not-entered`は現在応募できる企業・求人、採用温度、営業求人数の集計へ混ぜない。`pre-entry-signal`の現行求人は企業ページには表示できるが、日本進出済み企業の採用温度には混ぜない
- 日本進出時期や確率を確定情報として扱わず、公開事実から検証可能な仮説を組み立てる

## 2. 共通ページ構造

- 個別ページは共通の`CompanyIntelligenceProfile`と通常企業ページの標準セクション順を維持する
- 一覧カードには黄色の`日本未進出`ラベルを表示する。黄色は状態識別だけに使い、評価や推奨順位を示さない
- 上部サマリーでは、日本未進出の事実、海外での成長、APAC展開、進出を支持する材料と反証を簡潔に示す
- 会社概要の公式導線は英語の本国公式トップページとし、製品・採用・投資家ページで代用しない
- 会社全体のグローバル社員数を表示する。厳密値がなければLinkedIn企業ページ等の公開規模レンジを、出典と留保付きで掲載する
- 求人は日本向けが0件であることを明示し、海外求人の報酬・Quota・採用条件を将来の日本条件へ転用しない
- LinkedIn導線は日本在籍者検索ではなく、APAC・海外GTM人材の公開プロフィール検索とし、本文は対象地域・職種・サンプル数を示す集計に限定する

## 3. 「日本進出の可能性」の必須構造

見出しは`日本進出の可能性`に統一し、`japanGrowth.entryAssessment`を必ず設定する。

### 3.1 結論

`verdict`は、可能性の水準と、その判断を左右する最大の支持材料・反証を一文で示す。時期や確率を断定しない。

### 3.2 現在確認できる事実

`factSignals`を4件以上掲載する。Gongページと同様、少なくとも次の観点を横断する。

1. 会社規模、売上・ARR、成長率、顧客数、資金余力
2. 海外展開、APAC拠点、APAC求人、GTM体制
3. 製品の日本市場との親和性、日本語・ローカライズ状況
4. Enterprise導入に必要なSecurity、Trust、法規制・ガバナンス対応

各カードは公開事実として書き、`sourceIds`を必須とする。数字・日付・固有名詞は公開前に再確認する。

### 3.3 日本進出のハードル

`hurdles`を4件以上掲載する。製品ローカライズ、国内顧客証拠と販売導線、法務・Security・商習慣、既存競合・代替手段、初期GTM採算などから企業固有の障壁を示す。単に「競争が激しい」「知名度が低い」と書かず、なぜ現地投資の意思決定を遅らせるのかまで説明し、`sourceIds`を付ける。

### 3.4 日本進出が現実的になる条件

`readinessConditions`を5件以上掲載する。日本での有償顧客・pipeline、製品ローカライズ、国内導入の統制、初期GTM pod、reference customer・partnerなど、何が観測できれば進出仮説の確度が上がるかを具体化する。単なる希望ではなく、会社側が現地固定費を正当化できる条件として書く。

### 3.5 今後見るべきシグナル

`watchSignals`を6件以上掲載する。初回Japan求人、日本語サイト・UI、国内顧客事例、Japan territoryを持つAPAC人材、日本法人・Tokyo拠点、data region・サポート等、継続観測で確認できる公開イベントにする。

## 4. 必須調査範囲

- 企業公式のAbout、Press、決算・ARR、資金調達、顧客事例、製品、Trust/Security
- 公式Careersの採用地域、APAC求人、Japan・Tokyo・Japanese指定求人の有無
- 公式拠点一覧、APAC展開、partner、イベント、data region
- 製品UI、音声・言語対応、ヘルプセンター、サポートの日本語対応
- LinkedIn企業ページの会社規模レンジと、APAC・海外GTM人材の公開プロフィール集計
- 日本市場に関係する公的ガイドライン、規制、導入慣行、既存競合・代替手段
- 日本法人、国内求人、国内顧客、国内partnerが見つからないという反証

検索上位の数ページで終えず、強い支持材料と反証を同じ密度で集める。取得できない情報は推測で埋めず、未確認と明記する。

## 5. 仮説の書き方

- `事実 → Genbaの読み → 応募・継続観測判断への意味`を一続きにする
- 日本進出の時期、確率、最初の採用職種、報酬、Quotaを断定しない
- `2〜3年以内`等の時間軸はGenba仮説としてのみ扱い、支持材料、反証、確度、検証質問をセットにする
- 「会社が成長しているから日本へ来る」のような単線の推論を避ける。APAC優先順位、製品適合、顧客証拠、導入統制、初期GTM採算を組み合わせる
- 進出可能性が低い、または判断材料不足という結論も許容する。掲載企業を魅力的に見せるために結論を歪めない

## 6. 公開前チェック

- Gongページと実画面で比較し、同じセクション順と同等以上の情報密度になっている
- `entryAssessment`に結論、事実4件以上、障壁4件以上、現実化条件5件以上、観測シグナル6件以上がある
- 本国公式トップページとグローバル社員数の出典がある
- 日本向け求人0件と、日本進出を裏付ける情報が未確認であることを明示している
- すべての強い主張に公開ソースがあり、事実とGenba仮説が表示上も分かれている
- 国内情報不足を一般論や推測で埋めていない
- `npm run validate:playbooks`と`npm run check`が成功している

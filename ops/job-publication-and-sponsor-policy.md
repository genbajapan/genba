# 求人掲載・スポンサー運用ポリシー

最終更新: 2026-08-05

このファイルを、Genbaに求人情報を追加するとき、および法人スポンサー商品を販売するときの運用上の正本とする。

> この文書は社内運用ルールであり、個別案件についての法律意見ではない。収益化開始前、応募機能・候補者データ提供・成功報酬を導入する前には、募集情報等提供事業に詳しい弁護士・社労士または厚生労働省の窓口へ確認する。

## 1. 基本方針

Genbaは「求人転載サイト」や「人材紹介サービス」ではなく、公開された公式情報を独自に整理・分析する外資SaaS採用インテリジェンスメディアとして運営する。

- 読者は無料とする
- 求人への応募は各社の公式採用サイトで行う
- Genbaは応募を受け付けない
- 候補者と企業の面接調整・条件交渉をしない
- 採用成功報酬を受け取らない
- 候補者情報を本人の明示同意なく企業へ提供しない
- 広告料金によって求人順位・企業評価・分析結論を変えない

## 2. 求人情報は追加してよいか

企業から個別の掲載許可を取っていない場合でも、一般公開されている公式求人について、事実を独自に要約し、出典を付けて紹介できるものとする。

ただし、次の条件をすべて満たすこと。

- 情報源は企業の公式採用ページ、公式ATS、公式ニュースルームを優先する
- 求人票の文章・画像を丸ごとコピーしない
- 職種名、勤務地、担当領域、言語、公開日などの事実を独自の形式で整理する
- 必ず公式求人への直接リンクを付ける
- 初回確認日と最終確認日を保存する
- 募集終了・URL変更・内容変更を確認したら速やかに更新する
- 企業から合理的な訂正・削除依頼を受けた場合の窓口を用意する
- 推測を事実のように書かず、「Genba分析」と明示する

## 3. 1件ごとの必須データ

求人を公開する前に、最低限以下を記録する。

- `company_slug`: 企業ID
- `title`: 公式の職種名
- `location`: 勤務地
- `segment`: Enterprise、Mid-Market、SMB、Partnerなど
- `language`: 公式求人で確認できる場合のみ
- `source_url`: 公式求人URL
- `source_label`: 公式サイト・ATS名
- `first_seen`: 初回確認日
- `last_checked`: 最終確認日
- `status`: 公開中、変更、募集終了、確認不能
- `sponsored`: スポンサー掲載かどうか

報酬、OTE、リモート可否、担当社数などは、公式情報に記載がある場合だけ掲載する。推定値を確定情報として表示しない。

応募可能性、営業組織、報酬、人材流動を扱う場合は、さらに以下を守る。

- 応募・合否実績と公開済み算出方法がない状態で、個人の合格確率を数値表示しない
- 求人要件との一般的な一致点を示す場合も、合格可能性ではないことを明記する
- 社員数、AE人数、平均在籍年数、入社元、転職先は、対象地域・職種・期間・サンプル数・出典を併記した集計値に限定する
- 公開プロフィールを根拠にする場合も、個人名一覧、人物評、未確認の異動理由を作らない
- カントリーマネージャーや営業リーダーは、公式プロフィール、就任発表、本人の公開インタビューのみを参照する
- OTE、Pay Mix、Quota達成率はグローバル値と日本値を混同しない。日本の値を確認できない場合はその旨を表示する

## 4. 公開前チェックリスト

- [ ] 公式情報を開いて求人が現在も存在することを確認した
- [ ] 求人票の本文を大量に転載していない
- [ ] 公式求人への直接リンクが機能する
- [ ] 初回確認日・最終確認日が正しい
- [ ] 事実とGenba分析が表示上分かれている
- [ ] 給与・言語・勤務形態を推測で補っていない
- [ ] 非公開情報、勤務先で得た情報、個人情報を含まない
- [ ] スポンサー案件の場合は広告表記がある
- [ ] 同じ求人が重複登録されていない

## 5. 使用しないもの

- 許諾のない企業ロゴ、採用画像、社員写真
- 求人票本文の大部分または全文
- ログインが必要な非公開求人
- 求職者・社員個人に関する未確認情報
- 社内資料、顧客情報、非公開の採用計画
- 出典を確認できないSNS投稿だけに基づく求人
- 求人企業を装う表示、公式提携と誤認させる表示

企業名・サービス名は情報識別のためテキストで記載する。ロゴを使用する場合は、各社のブランドガイドラインまたは個別許諾を確認する。

## 6. 職業安定法上の境界

企業から依頼を受けずに公開求人を収集し、職業選択を容易にする目的で提供する行為も「募集情報等提供」に含まれ得る。Genbaは、募集情報の的確な表示、最新性、苦情・訂正対応を運用要件として扱う。

当面、以下は実施しない。

- Genba内での応募受付
- 読者ごとに企業を選別して個別紹介すること
- Genbaの判断による候補者と求人のマッチング
- 応募書類の企業への転送
- 面接日程や企業・候補者間の連絡の仲介
- 内定条件や報酬の交渉
- 採用成立を条件とした成功報酬

これらを導入する場合は、職業紹介事業の許可が必要か事前確認する。

読者の職歴、転職意向、希望条件、連絡先などを収集し、求人企業等への情報提供に使用する場合は、「特定募集情報等提供事業」の届出が必要になる可能性が高い。導入前に必ず確認する。

ニュースレターのメールアドレスは配信目的だけに使用し、以下を守る。

- 利用目的を登録時に明示する
- スポンサー企業へ個人単位で提供しない
- スポンサーへのレポートは集計値だけにする
- 解除方法と問い合わせ窓口を表示する
- プライバシーポリシーを公開する

## 7. スポンサーから受け取る対価

スポンサーは「求人を掲載する権利」や「良い評価」を買うのではない。外資SaaS営業人材に対して、採用背景・営業組織・仕事の魅力を継続的に説明し、認知・理解・公式求人への送客を得るために支払う。

企業側の主な便益は以下。

1. 一般求人媒体だけでは届きにくい、転職潜在層を含む現役AEへの到達
2. 求人票だけでは伝わらない日本事業・営業組織・担当市場の説明
3. 転職検討前からの継続的な企業想起
4. 公式求人へのクリック、コンテンツ閲覧などの集計レポート
5. 外資SaaS営業に特化した文脈の中での信頼形成

## 8. 販売商品の設計

### 無料掲載

- 基本企業ページ
- 公式求人へのリンク
- 公開情報から確認した採用シグナル
- 出典・確認日・通常の編集分析

無料掲載の有無や内容はGenbaが編集判断する。

### 採用パートナー

- スポンサー表示付き企業プロフィールの拡充
- 募集中の営業求人の継続反映
- 日本市場、営業組織、求める人物像を扱うスポンサー企画
- ニュースレターのスポンサー枠
- `@chosenshi08`でのPR表記付き配信
- 公式求人へのクリック・閲覧の集計レポート

掲載企業に、通常記事の評価、ランキング順位、分析結論を変更する権利は与えない。事実誤認の修正とスポンサー制作物の事実確認は受け付ける。

### その他のスポンサー

- ニュースレタースポンサー
- 外資SaaS採用に関係するイベント掲載
- ATS、採用管理、営業支援など読者との関連性が高いサービス

読者との関連性が薄い広告は受けない。

## 9. 価格の目安

媒体立ち上げ期は、効果検証を優先する。

- 初期3社の実証プラン: 月額5万〜10万円、1カ月
- 効果確認後の採用パートナー: 月額15万〜25万円
- 月間訪問者1万人・メール読者3,000人程度に到達後: 月額25万〜40万円

契約前に、料金、発生条件、期間、解約方法、追加費用を電子メールまたは契約書で明確に提示する。

目標モデル:

- 採用パートナー4社 × 25万円 = 100万円
- ニュースレタースポンサー2社 × 15万円 = 30万円
- 月間売上 = 130万円
- 運営・外注・ツール費 = 20万〜30万円以内
- 月間利益 = 約100万円

## 10. 支払企業の優先順位

1. 自社採用を行う外資SaaS企業
2. 外資SaaS採用に強い人材紹介会社。ただし成功報酬や候補者情報提供は行わない
3. ATS、採用管理、営業支援など読者に関係するB2B企業
4. キャリア関連サービス

読者の信頼を損なう可能性がある場合は、売上より掲載拒否を優先する。

## 11. 収益化開始前の必須条件

- [ ] 勤務先の副業・外部活動・競業規定を確認した
- [ ] 募集情報等提供事業として必要な対応を専門家または行政窓口に確認した
- [ ] スポンサー掲載規約・料金・解約条件を作成した
- [ ] プライバシーポリシーを公開した
- [ ] 広告・PR表示ルールをサイトに公開した
- [ ] 求人の訂正・削除依頼窓口を用意した
- [ ] 求人の終了確認フローを運用できる
- [ ] 読者の個人情報をスポンサーへ提供しない設計を確認した

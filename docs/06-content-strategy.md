# コンテンツ・発信戦略

英語メディア(ブログ)+ 英語Xアカウントで、下記5カテゴリをローテーションしながら日次で発信する。

## 5つのコンテンツカテゴリ

### 1. 商習慣・意思決定プロセス
稟議・根回し、名刺交換や上下関係が商談に与える影響、初回商談で決まらない理由 など

### 2. 業界別の勘所
- リテール/EC: モール経由購買の強さ、カスタマーサポート期待値
- OTA/旅行: インバウンド動向、既存プレイヤーとの関係構築

### 3. 市場データ・トレンド
EC市場規模、キャッシュレス比率、インバウンド消費額など一次情報(経産省・観光庁・JETRO等)を引用

### 4. セールス実践・戦略
現地法人 vs 代理店 vs フラクショナル営業の比較、価格ローカライズの失敗パターン、最初のリファレンス顧客の獲得法

### 5. ケーススタディ・失敗談
「なぜ進出後に伸び悩むのか」を中心とした診断系コンテンツ。**既存競合が手薄な領域**([07-competitive-landscape.md](07-competitive-landscape.md)参照)

## 発信時の必須ガードレール

**全発信前に [ops/guardrails.md](../ops/guardrails.md) を確認すること。**

要点:
- Adyenの社名・内部の案件・顧客情報・価格戦略には一切言及しない
- 発信は個人の一般化できる経験・見解として書き、Adyenを代表する見解であるかのような書き方は避ける
- プロフィールにAdyen在籍を記載すること自体は問題ないが、実績訴求はCisco/Shopify時代の経験を中心に据える

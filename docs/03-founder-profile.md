# 創業者(Jio)のバックグラウンドと強み

## 経歴

| 期間 | 会社 | 役割 |
|---|---|---|
| 過去 | Cisco Systems | 営業(2年10ヶ月) |
| 過去 | Shopify Japan | 営業(4年半) — 外資系ECプラットフォームの日本立ち上げ・拡大に現場で従事 |
| 2026-09-01〜 | Adyen | エンタープライズセールス。決済領域、OTA/旅行/観光業界との接点あり |

## 特性

- 日本語・英語バイリンガル。日本育ち
- SDR → BDR → AE と、セールスプロセスの全ロールを経験した上でSMB→ミッドマーケット→エンタープライズとステップアップしてきた経歴。特定のディール規模に限定せず支援可能
- 業界としては特にリテール/D2C領域に強み

## メディアを始めた動機

外資系企業の日本法人でAEとして働く中で、海外(本社側)のエグゼクティブが日本の商習慣を理解しないまま日本市場向けの意思決定を行い、現場の実態と合わないKPIや施策が降りてくる、という問題を繰り返し経験した。現場は何をすべきか分かっているのに優先度を上げてもらえない——本社側に「自分たちが何を分かっていないか」を理解する材料がないためだった。

その結果として、市場が本来出せたはずの成果が出ない、優秀な現場の営業メンバーがやる気を失う・離職する、といった実害が生じていた。Genbaは、この「本社の前提」と「日本市場の実態」のギャップを埋めることが事業の根本的な動機。

## 差別化となる強み

「外から見た市場参入戦略」ではなく、**「外資系企業の中で実際に日本のエンタープライズ商談を回し、成果を出してきた」現場経験**。

既存のJapan GTM系エージェンシー([07-competitive-landscape.md](07-competitive-landscape.md)参照)にはない、個人の実績に基づく説得力が差別化要素。
